Privacy

Last updated 2026-11-25. Christopher DeFoe runs skycake.app. The viewer has no accounts, runs no analytics or advertising, loads nothing from other sites and sets no cookies of its own.

Cloudflare Pages hosts the site. Each file request reaches Cloudflare with the browser's IP address, user agent and the requested URL, which can show the area or chart asked for. Cloudflare may log these details to deliver and secure the site, under the Cloudflare privacy policy. Christopher DeFoe keeps Cloudflare Web Analytics off and does not use request logs to identify visitors.

Before launch, Cloudflare Access limits skycake.app to invited testers. Signing in sets Cloudflare's session cookie, CF_Authorization, and Cloudflare records each sign-in attempt, including the tester's email address and IP address. Christopher DeFoe can see those records to manage tester access. The sign-in and cookie end when skycake.app opens to everyone.

The browser keeps some data on the device. The app's own files are cached so the viewer opens offline. Saving an area offline adds that area's files to the browser's Cache Storage and asks the browser to keep them. Accessibility mode stores one setting, skycake-a11y, in local storage. The start screen removes each saved area, and clearing site data in the browser's settings removes everything.

Questions go to GitHub issues, which are public, so leave personal details out. GitHub handles those visits under the GitHub privacy statement. This notice may change, and the date at the top shows the latest revision.
