# Code of Conduct

This project is a place to build skycake, ask questions and fix bugs together. Everyone taking part in its issues, pull requests and discussions agrees to:

- Be respectful and patient, with beginners especially.
- Criticise code and ideas, not people.
- Stay on topic.

Not accepted: harassment, insults, discriminatory jokes or language, personal attacks, sexual content, publishing someone's private information, and anything else a reasonable person would find unwelcome.

## Enforcement

Report a problem to Chris DeFoe at chris@defoe.me. Reports are kept private. The maintainer may edit or delete comments, lock threads, and block anyone who breaks this code, temporarily or permanently.

This code applies in all project spaces and when someone represents the project elsewhere.
